# Noor Ride

This repository contains a simple landing page for the Noor Ride brand.

## Included
- Responsive homepage
- Service highlights
- Booking/contact section
- GitHub Pages-ready `CNAME` file

## Local preview
Open `index.html` in a browser or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages
If you connect a custom domain, make sure your DNS points to GitHub Pages and the `CNAME` file remains in the repository root.
